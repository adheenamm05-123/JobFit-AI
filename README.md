# 🤖 JobFit AI

AI-powered Resume Analyzer and Job Matching System built using Python and Streamlit.

## 🚀 Features

* Resume Upload (PDF)
* Resume Parsing
* Skill Extraction
* Job Matching
* Resume vs Job Description Analysis
* ATS Score
* AI Career Suggestions
* Best Matching Job Recommendation

## 🛠 Technologies

* Python
* Streamlit
* Pandas
* Google Gemini API
* pdfplumber

## ▶️ Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
